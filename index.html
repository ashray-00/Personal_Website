Real-time voice agent with interrupt capability. The pipeline chains VAD → STT → turn detection → LLM → TTS, targeting 500–600ms voice-to-voice. Rolling partial transcripts keep the STT stage from blocking the response path.

The hard part was barge-in: the agent runs a state machine (LISTENING → THINKING → SPEAKING → INTERRUPTED) while a parallel VAD thread filters playback echo using correlation thresholds and a ~200ms energy-hold gate — so the agent stops talking when the user interrupts, not when it hears itself.

Python · faster-whisper · Silero VAD · OpenAI LLM/TTS · llama.cpp · Tavily
sqlite-hybrid-search
GitHub PyPI

In-process C++17 library that fuses dense HNSW vector search (usearch) and BM25 full-text retrieval (SQLite FTS5) via Reciprocal Rank Fusion with per-chunk exponential recency decay. Single-writer/concurrent-reader WAL concurrency, no external locking. Pimpl public API. nanobind Python bindings with prebuilt wheels for Linux x86-64 and macOS Apple Silicon.

Cold-start time cut from 14.6 seconds to ~40ms by persisting the HNSW graph to disk. The whole retrieval stack fits in-process — no network hop, no separate service.
